# MCP для ORBIT

Веб-студия: https://orbit-keyboard-studio-29oct.druidbeat.chatgpt.site/

MCP endpoint: https://orbit-keyboard-studio-29oct.druidbeat.chatgpt.site/mcp

## Как пользоваться

1. Подключите личный плагин ORBIT в ChatGPT или Codex. Он создаётся при публикации сайта с MCP.
2. Откройте веб-студию и дождитесь индикатора **MCP ● подключён** внизу.
3. Один раз нажмите **Start Audio**. После этого чат может играть ноты, запускать паттерны и запись.

Если открыто несколько студий, сначала получите `orbit_list_sessions` и выберите `session_id` нужной вкладки. Кнопка MCP внизу отключает управление этой вкладкой.

## Команды

| Инструмент | Что делает |
|---|---|
| `orbit_list_instruments` | Каталог 36 тембров с ID и категориями |
| `orbit_list_sessions` | Подключённые вкладки |
| `orbit_get_state` | Темп, тембр, транспорт, эффекты и готовность звука |
| `orbit_get_project` | JSON проекта без аудиобайтов сэмплов |
| `orbit_configure` | Тембр, темп, тональность, ADSR, эффекты, арпеджиатор, избранное |
| `orbit_transport` | Play, Pause, Stop, начало/окончание записи |
| `orbit_play_notes` | Короткие ноты и аккорды с автоматическим отпусканием |
| `orbit_trigger_pad` | Аккорд, ударный звук, нота гаммы или локальный сэмпл |
| `orbit_set_pattern` | Мелодия и барабаны в секвенсоре |
| `orbit_edit_notes` | Ноты в Piano Roll |
| `orbit_generate_progression` | House, Techno, Trance, Ambient, Synthwave, Lo-fi |
| `orbit_history` | Undo / Redo |
| `orbit_export` | Скачивание JSON, MIDI или WAV через браузер |
| `orbit_load_project` | Загрузка JSON проекта в выбранную сессию |
| `orbit_command_status` | Результат ранее поставленной в очередь команды |

ID инструментов и пэдов начинаются с 0. MIDI-нота 60 — C4. `duration_beats` измеряется в четвертных долях; шаги секвенсора и Piano Roll — в шестнадцатых. Ритмические партии создавайте через `orbit_set_pattern`: их тайминг планирует аудиодвижок в браузере.

Примеры запросов: «Выбери арфу, поставь 110 BPM и сыграй C–E–G»; «Создай house-паттерн в A minor»; «Добавь мелодию в Piano Roll и экспортируй WAV».

MCP работает с открытой веб-версией. Автономный HTML по-прежнему играет без сети; его кнопка MCP открывает веб-студию. Аудиосэмплы остаются в браузере. Для полного сохранения сэмплов используйте JSON-экспорт.
