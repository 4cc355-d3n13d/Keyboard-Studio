# ORBIT — Music Keyboard Studio

Браузерная музыкальная студия с 36 синтезированными инструментами, клавиатурой, пэдами, секвенсором, Piano Roll и эффектами. Работает как автономный HTML и как веб-приложение с управлением через MCP.

**Версия приложения:** 2.0.0 · **Формат проекта:** version 1 · **Документация:** 30 октября 2026 года.

[Открыть веб-студию](https://orbit-keyboard-studio-29oct.druidbeat.chatgpt.site/) · [Автономный HTML](music-keyboard-studio.html) · [Полная документация](ORBIT-Documentation.html)

## Возможности

- 36 тембров: клавишные, синтезаторы, басы, струнные, духовые, колокольчики и характерные инструменты.
- Игра мышью, касаниями и физической клавиатурой; Sustain, pitch bend, modulation и velocity.
- 16 пэдов в режимах аккордов, ударных, сэмплов и ступеней гаммы.
- Секвенсор на 16/32 шага: мелодия и четыре строки барабанов.
- Запись исполнения, редактирование Piano Roll, квантование и Undo/Redo.
- Восемь эффектов, XY-площадка, арпеджиатор, Swing и Humanize.
- Четырёхканальный микшер, Scale Lock, избранные инструменты и генератор гармонии.
- Playground с упражнениями на мелодию, ритм, аккорды и создание бита.
- Сохранение JSON, экспорт MIDI и стерео WAV.
- 15 MCP-инструментов для управления подключённой веб-студией из чата.

## Быстрый старт

### Веб-версия

1. Откройте [ORBIT](https://orbit-keyboard-studio-29oct.druidbeat.chatgpt.site/).
2. Нажмите **Start Audio**.
3. Выберите тембр и сыграйте клавишами или пэдами.
4. Нажмите **Play**, чтобы запустить секвенсор.
5. Нажмите **Сохранить**, чтобы скачать полный JSON-проект.

Для работы с текущей веб-публикацией требуется доступ к сайту. После перезагрузки страницы аудиоконтекст нужно запустить заново.

### Автономная версия

Откройте [music-keyboard-studio.html](music-keyboard-studio.html) в браузере и нажмите **Start Audio**. Tone.js встроен в файл; подключение к интернету для игры не требуется.

Удалённый MCP управляет веб-сессиями. Вкладка `file://` работает самостоятельно; её кнопка MCP открывает веб-студию. Проекты между версиями переносятся через JSON.

## Основное управление

| Действие | Управление |
|---|---|
| Белые клавиши | A, S, D, F, G, H, J, K, L, ;, ' |
| Чёрные клавиши | W, E, T, Y, U, O, P, ] |
| Сменить октаву | Z / X |
| Включить/остановить транспорт | Space |
| Временный Sustain | Shift |
| Первые восемь пэдов | Цифры 1–8 |
| Отменить / повторить правку | ⌘/Ctrl+Z / ⌘/Ctrl+Shift+Z |
| Назначить ноту шага | Shift+клик или правый клик по мелодической ячейке |
| Добавить ноту Piano Roll | Двойной клик по пустому месту |
| Удалить событие Piano Roll | Правый клик по событию |

Музыкальные клавиши используют физические позиции клавиатуры. Когда фокус находится в поле ввода или выпадающем списке, игровые сочетания обычно не обрабатываются.

Один шаг секвенсора — шестнадцатая: 16 шагов составляют один такт 4/4, 32 — два такта. Секвенсор и записанная партия Piano Roll звучат совместно. Undo/Redo откатывает паттерн, события и длину, а не все настройки студии.

## Управление через MCP

**Плагин:** ORBIT — Music Keyboard Studio.

**MCP endpoint и OAuth resource:**

```text
https://orbit-keyboard-studio-29oct.druidbeat.chatgpt.site/mcp
```

Подключите личный плагин в поддерживаемом клиенте, откройте веб-студию и дождитесь **MCP ● подключён**. Для звуковых команд один раз нажмите **Start Audio** в этой вкладке.

Примеры запросов в чате:

- «Выбери арфу и сыграй C–E–G».
- «Поставь 110 BPM и добавь немного реверберации».
- «Создай house-паттерн в A minor».
- «Добавь мелодию в Piano Roll и экспортируй WAV».

| MCP-инструмент | Назначение |
|---|---|
| `orbit_list_instruments` | Каталог 36 тембров с ID |
| `orbit_list_sessions` | Подключённые веб-вкладки пользователя |
| `orbit_get_state` | Последний снимок настроек и состояния |
| `orbit_get_project` | Проект без аудиобайтов сэмплов |
| `orbit_configure` | Тембр, темп, тональность, звук, эффекты и арпеджиатор |
| `orbit_transport` | Воспроизведение, пауза, остановка и запись |
| `orbit_play_notes` | Короткая нота или аккорд |
| `orbit_trigger_pad` | Запуск пэда |
| `orbit_set_pattern` | Редактирование секвенсора |
| `orbit_edit_notes` | Добавление или замена нот Piano Roll |
| `orbit_generate_progression` | Создание паттерна по стилю |
| `orbit_history` | Undo / Redo |
| `orbit_export` | Скачивание JSON, MIDI или WAV в браузере |
| `orbit_load_project` | Замена текущего проекта |
| `orbit_command_status` | Результат ранее отправленной команды |

### Пример: концертная арфа и C–E–G

Сначала вызовите `orbit_list_sessions`. Если сессий несколько, передавайте `session_id` выбранной вкладки в следующие команды.

Выбор Concert Harp, ID 24:

```json
{
  "name": "orbit_configure",
  "arguments": {
    "session_id": "SESSION_ID",
    "instrument_id": 24
  }
}
```

После подтверждения выбора инструмента:

```json
{
  "name": "orbit_play_notes",
  "arguments": {
    "session_id": "SESSION_ID",
    "notes": [60, 64, 67],
    "duration_beats": 4,
    "velocity": 0.8,
    "respect_scale": false
  }
}
```

Замените `SESSION_ID` реальным значением. ID инструментов и пэдов начинаются с нуля. MIDI 60 = C4. `duration_beats` измеряется в четвертных долях, а времена Piano Roll — в шестнадцатых шагах.

Если ответ содержит `status: "pending"`, проверьте `orbit_command_status` с полученным `command_id` перед повторной отправкой. Браузер кэширует результаты для повторного ack, но перезагрузка вкладки очищает этот кэш: строгая гарантия exactly-once не заявлена.

Для ровного музыкального ритма задавайте паттерн и запускайте транспорт. Интервалы между отдельными сетевыми командами не являются музыкальным расписанием.

## Сохранение и экспорт

| Формат | Для чего использовать |
|---|---|
| JSON | Переносимый редактируемый проект с настройками, нотами и встроенными сэмплами |
| MIDI | Ноты и барабанные события для другой музыкальной программы; без аудиосэмплов и эффектов |
| WAV | Готовый звук одного цикла с рассчитанным хвостом эффектов; стерео PCM 16 bit, 44.1 kHz |

**Автосохранение не включает аудиобайты пользовательских сэмплов.** Перед закрытием такого проекта скачайте полный JSON через **Сохранить** или MCP-экспорт JSON. Избранное хранится отдельно в браузере.

WAV рендерится локально и останавливает транспорт. Экспорт строится из шагов и сохранённых событий; live-арпеджиатор, Swing и случайный Humanize не запекаются автоматически как запись системного выхода. Результат MCP-экспорта подтверждает запуск браузерного скачивания, а не путь к файлу в окружении агента.

## Исходники и сборка

Скачайте [архив исходников](orbit-mcp-source.zip) и распакуйте его. Команды выполняются из корня исходников `orbit-mcp/`.

Требуется Node.js 22.13+; в README исходной версии рекомендован Node.js 24. Зависимостей npm нет, установка пакетов для сборки не нужна. Backend-тесты используют встроенный `node:sqlite`.

```sh
node scripts/build-mcp.mjs
node scripts/validate-mcp-artifact.mjs
node --test tests/mcp.test.mjs
```

После изменения исходников сначала пересоберите проект: тесты читают готовый Worker из `dist/`.

```text
web/index.html                   UI, state, пресеты и аудиодвижок
web/tone.js                      Встроенная библиотека Tone.js
mcp/protocol.js                  15 tools, схемы и валидация
mcp/browser.js                   OrbitControl и браузерный MCP-мост
worker/server.js                 HTTP, авторизация, очередь и JSON-RPC
drizzle/                         Миграции D1
scripts/build-mcp.mjs             Сборка Worker и автономного HTML
scripts/validate-mcp-artifact.mjs  Проверка собранного артефакта
tests/                           Backend-тесты и тестовый адаптер D1
.openai/hosting.json              Конфигурация Sites
```

Результаты сборки:

- `dist/server/index.js` — Worker ESM для размещения.
- `dist/.openai/hosting.json` — metadata размещения.
- `build/index.html` — веб-страница, ожидающая соседний `tone.js`.
- `build/catalog.json` — каталог инструментов.
- `build/music-keyboard-studio.html` — самодостаточный HTML.

Редактируйте исходники в `web/`, `mcp/` и `worker/`: прямые правки сгенерированных файлов будут потеряны при сборке.

## Архитектура и размещение

```text
MCP-клиент → Sites Worker → D1-очередь → poll открытой студии
                                           ↓
                                    OrbitControl.invoke
                                           ↓
                                     Tone.js / Web Audio
```

Worker обслуживает страницу, библиотеку, загрузку standalone, `/mcp` и браузерный API `/api/orbit/*`. Студия последовательно выполняет команды и отправляет ack. Read-only состояние и проект читаются из последнего серверного снимка; его возраст указан в `snapshot_age_ms`.

Текущий manifest объявляет `capabilities: ["mcp"]`, D1 binding `"DB"`; R2 не используется. Публикация выполняется через Sites с сохранением аудитории и соответствием архива точному pushed commit. Полный порядок описан в документации.

Идентификацию в production обеспечивает доверенный заголовок Sites `oai-authenticated-user-id`. При переносе на другой хостинг замените `orbitUser` настоящей проверкой личности: доступный извне пользовательский заголовок сам по себе не является авторизацией.

Серверный снимок — кэш для MCP, а не резервная копия проекта. Обычно снимки не содержат аудио; если передать `sample.data` в `orbit_load_project`, эти данные попадут в аргументы серверной команды. Не сохраняйте credentials в коде, проектах или документации.

## Ограничения

- Один выбранный мелодический тембр; отдельные live/seq/remote-голоса не являются независимыми инструментальными дорожками.
- Удалённый звук требует открытой веб-студии и запуска аудио в браузере.
- Нет VST/AU, импорта MIDI, микрофонной записи, Web MIDI и постоянного облачного архива песен.
- MCP-запрос ограничен 512 KiB; крупные JSON-проекты открывайте файловым интерфейсом.
- До 12 нот и до 4 четвертей удержания в одном `orbit_play_notes`; до 4096 событий проекта.
- Политика браузера влияет на автосохранение `file://`, фоновую работу и скачивания.
